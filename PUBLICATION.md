# Public source and private runtime data

Personal test phone numbers, VINs and registration numbers have been replaced with synthetic fixtures throughout the Git history. Runtime credentials, customer databases and saved browser sessions are excluded from version control.

The history was rewritten for publication. Existing collaborators must use a clean clone or rebase their own changes onto the rewritten history. Do not merge an old clone or push its old branches: this can restore removed data.

Use environment variables for private pilot identifiers. A deployment must use its own credentials, authorized recipient list and supplier accounts. No software license is added by this publication.
